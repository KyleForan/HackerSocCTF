# TUD Ethical Hacker Society Intro CTF Challenges  
---  
 
## Introduction 
These challenges are designed to help beginners starting with Capture the Flags.  
Each category has challenges designed to walk through basic concepts of the category.  

## Recomended CTF platforms
 - https://play.picoctf.org
 - https://cybersecuritychallenge.ie/
 - https://overthewire.org/wargames/

## Binary Exploitation
### Recommended Tools:
 - pwntools
 - ghidra / binary ninja
 - python
  
### Resources:
 - https://ir0nstone.gitbook.io/notes/misc/pwntools
 - https://pwn.college
 - https://ropemporium.com/
